# Upgrading to PHPStorm 2025.2
Immediately after upgrade to PHPStorm 2025.2 I noticed the integrated terminal had changed. Previously I know I forced the terminal to use the "Classic" engine because I remember not being a fan of the "Reworked" version for whatever reason when that came about. 

In this new terminal, there are now these distracting lines between each command. This is personal preference but I like my workspace to be **as minimal as possible**. I loathe clutter and unnecessary icons and buttons but I love the convenience that an IDE like PHPStorm provides.

I quickly found where these dividers could be turned out and shut that down immediately

```
Settings | Tools | Terminal | Show separators between executed commands
```
