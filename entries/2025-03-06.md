## MySQL SSH Tunnel for Laravel

```
ssh -N -L 13306:127.0.0.1:3306 stagedb.wcv
```

```
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=13306
DB_DATABASE=
DB_USERNAME=
DB_PASSWORD=
```
